# FULTUS

## APP Description

Fultus is a SaaS Customer Support Platform where business can manage customer inquiries, track support tickets, assign tickets to employees, and monitor customer satisfaction.

## Main Features

### Authentication and authorization
- User registration and login.
- JWT authentication.
- Role-based access control:
  - Admin
  - Support Agent
  - Customer
### Ticket management
- Customers can create support tickets.
- Agents can assign tickets to themselves or other agents.
- Update ticket status: Open, In Progress, Resolved, Closed.
- Set ticket priority: Low, Medium, High, Critical.
- Add comments and responses.
- Search and filter tickets.
### Dashboard and analytics
- Total tickets.
- Open versus resolved tickets.
- Average resolution time.
- Customer satisfaction.
- Tickets assigned to each agent.
### Additional features
- Email notifications.
- Ticket activity history.
- File attachments.
- Internal notes visible only to support agents.
